# All Access Pass

The All Access Pass includes all current Church Plugins and every future plugin, under one license key. Use that same key in each plugin you install.

## Download the plugins

1. Log in to [My account](https://churchplugins.com/account/).
2. Open the Downloads tab. Each plugin has a zip link in the files column.
3. Open the Licenses tab. Your key and its status are in the license details column.

If you cannot find a download, the Downloads tab includes this line: "Can't find a download or need help with a license? Contact support".

## Install a plugin

Church Plugins are not listed in the WordPress plugin search. Install each one from its zip file.

1. Log in to your WordPress dashboard.
2. Go to Plugins → Add Plugin → Upload Plugin.
3. Choose the zip file and click Install Now. Do not unzip the file first.
4. After the install finishes, click Activate Plugin.
5. Repeat for each plugin you downloaded.

## Activate your license

One All Access Pass key activates every plugin. Paste the same key in each plugin.

For CP Sermons, CP Groups, CP Staff, CP Live, and CP Locations:

1. Open the plugin's License tab (see the table below).
2. Enter your key in the License Key field.
3. Click Save Changes. The Activate License button appears after the key is saved.
4. Click Activate License.
5. A green check mark appears next to the key when the license is active.

To move a license off a site later, return to the same License tab and click Deactivate License.

For CP Sync, the buttons work a little differently:

1. Go to Church Plugins → CP Sync, then open the License tab.
2. Enter your key in the License Key field.
3. Click Activate. Activate and Deactivate save on their own. You do not need to click Save all Settings first.

### Where to find the License tab

| Plugin | Go to |
|---|---|
| CP Sermons | Series → Settings → License. If Series is turned off, use Messages → Settings → License. |
| CP Groups | Groups → Settings → License |
| CP Staff | Staff → Settings → License |
| CP Live | Settings → CP Live → License |
| CP Locations | Locations → Settings → License |
| CP Sync | Church Plugins → CP Sync → License |

## Move a license to a new site

If you are moving a site, deactivate the license in the plugin on the old site first, then activate the same key on the new site. This works on every plan.

If your plan covers more than one site, you can also activate the key on additional sites, up to the number of sites in your plan.

## Good to know

- Lifetime licenses do not expire.
- Every plan, including Lifetime and the All Access Pass, has a 30-day full refund. Open a support ticket to ask.
- Updates need an active license key. Without one, the plugin will not get new versions.
